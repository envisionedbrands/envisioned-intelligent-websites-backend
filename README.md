# Envisioned Intelligent Websites — Backend

The brain behind your AI-powered website. Writes articles for you. Stores leads. Manages everything.

Pairs with the [frontend template](https://github.com/envisionedbrands/envisioned-intelligent-websites-frontend) to give you a complete site, or works standalone if you have your own website.

---

## 🚀 Set up in two steps

### Step 1 — Prep *(15 min)*
Create a few accounts and grab some keys. Plain-language walkthrough here:
**👉 [PREP-BEFORE-INSTALL.md](https://gist.github.com/envisionedbrands/646e94e9c1b95f2b5bb97e95a197a319#file-prep-before-install-md)**

### Step 2 — One-command install *(10 min)*
Open Terminal on your Mac (Cmd+Space → "terminal" → enter) and paste:

```
bash <(curl -fsSL https://gist.githubusercontent.com/envisionedbrands/646e94e9c1b95f2b5bb97e95a197a319/raw/envisioned-install.sh)
```

This installs **both** the backend and the frontend, set up under your own GitHub + Cloudflare + Supabase accounts. At the end you'll have two live URLs.

You don't need to know any code. The script asks for the values you saved in Step 1, fills everything in for you, and deploys.

---

## What you get

A live admin dashboard at `https://your-name.workers.dev` where you can:

- Click "Write Article" → AI writes a blog post in your voice
- See leads coming in from your contact form
- View visitor analytics
- Manage your wiki *(optional)*
- Run the AI content pipeline (idea → outline → draft → publish)
